# Кардио-калькулятор — веб-версия

Статическая PWA-версия приложения для удалённого доступа с iPhone (Safari →
«Добавить на экран «Домой»»). Публикуется через GitHub Pages из этой папки
(`docs/`, ветка `main`).

Версия 3.0 (веб) обновлена по полному разбору текущей Android-версии
(`MainActivity.kt`, `Calculators.kt`, `ui/theme/*.kt`) поверх более ранней
версии 2.0 ("с нуля"):
- добавлена вкладка **"ФП"** (переключатель "Основные шкалы" / "CHA2DS2-VASC
  / HAS-BLED" под шапкой) со шкалами **CHA2DS2-VASc** и **HAS-BLED**, включая
  общие с вкладкой "ОКС" поля (возраст, пол, АД сист., ХСН, диабет,
  сосудистое заболевание, инсульт/ТИА) и документированные подсказки под
  чекбоксами "Нарушение функции почек"/"печени";
- новая система тем: наборы "фон + акцент" (7 предустановленных пар для
  светлой и тёмной темы) вместо одной палитры фона — свотчи показывают
  акцентный цвет, выбор применяется по нажатию "Готово";
- в меню добавлен пункт **"Поделиться"** (Web Share API со ссылкой на
  RuStore, с запасным вариантом — копированием ссылки в буфер обмена);
- диалог "Формулы" сгруппирован по карточкам: "Основные шкалы" и
  "CHA2DS2-VASc / HAS-BLED".

Формулы, видимость полей, акцентные цвета, переключатель пола (иконки) и
поведение «не требуется» воспроизведены по фактическому коду приложения.

Файлы:
- `index.html`, `styles.css`, `app.js` — интерфейс и логика приложения.
- `calculators.js` — прямой порт `Calculators.kt` (формулы шкал, включая
  CHA2DS2-VASc и HAS-BLED).
- `manifest.webmanifest`, `sw.js` — установка как приложение и офлайн-кеш.
- `icons/` — иконка приложения и иконки переключателя пола (те же PNG,
  что используются в Android-приложении).
