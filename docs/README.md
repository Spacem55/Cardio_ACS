# Кардио-калькулятор ОКС — веб-версия

Статическая PWA-версия приложения для удалённого доступа с iPhone (Safari →
«Добавить на экран «Домой»»). Публикуется через GitHub Pages из этой папки
(`docs/`, ветка `main`).

Версия 2.0 (веб) построена «с нуля» на основе полного разбора текущей
Android-версии (`MainActivity.kt`, `Calculators.kt`, `ui/theme/*.kt`):
формулы, видимость полей, палитра фона, акцентные цвета, переключатель
пола (иконки) и поведение «не требуется» воспроизведены по фактическому
коду приложения, а не по более ранней (частично устаревшей) веб-версии.

Файлы:
- `index.html`, `styles.css`, `app.js` — интерфейс и логика приложения.
- `calculators.js` — прямой порт `Calculators.kt` (формулы шкал).
- `manifest.webmanifest`, `sw.js` — установка как приложение и офлайн-кеш.
- `icons/` — иконка приложения и иконки переключателя пола (те же PNG,
  что используются в Android-приложении).
