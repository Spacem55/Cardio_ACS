# Кардио-калькулятор ОКС — веб-версия

Приложение «Кардио-калькулятор ОКС».
Открывается в любом браузере, включая Safari на iPhone; через
«Поделиться → На экран «Домой»» превращается в иконку, похожую на
обычное приложение (PWA, работает офлайн после первого открытия).

Логика расчётов (`calculators.js`) — прямой порт `Calculators.kt` из
Android-версии, те же формулы: ИМТ, СКФ (CKD-EPI 2021), клиренс
креатинина (Кокрофт-Голт), шкала GRACE, шкала CRUSADE.

## Публикация на GitHub Pages

1. В настройках репозитория: **Settings → Pages → Source → Deploy from
   a branch**, ветка `main`, папка `/ (root)` (если содержимое этой
   папки `web/` лежит в корне репозитория) — сохранить.
2. Через 1-2 минуты сайт будет доступен по адресу вида
   `https://<username>.github.io/<repo>/`.
3. На iPhone открыть эту ссылку в Safari → значок «Поделиться» →
   «На экран «Домой»».

Никакой сборки не требуется — это обычные статические файлы
(HTML/CSS/JS), сервер не нужен.

## Структура

- `index.html` — разметка
- `styles.css` — стили (светлая/тёмная тема, палитра фона — как в Android-версии)
- `calculators.js` — чистая логика расчётов
- `app.js` — состояние, обработчики, рендер
- `manifest.webmanifest` + `sw.js` — PWA (иконка на экране «Домой», офлайн-режим)
- `icons/` — иконки приложения (192×192, 512×512)

## Важно

Приложение не является медицинским изделием и не заменяет консультацию врача.
