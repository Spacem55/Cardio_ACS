# Кардио ОКС — калькулятор шкал (Android 12+)

Проект для Android Studio: Kotlin + Jetpack Compose (Material 3), один экран,
вертикальная прокрутка. minSdk 31 (Android 12), сборка Gradle (Kotlin DSL).

## Важное отличие от исходного ТЗ

Шкала **CRUSADE** по определению требует **базовый гематокрит (%)** — этого
поля не было в списке полей, поэтому оно добавлено в блок
«Лабораторные и витальные показатели». Без него посчитать CRUSADE корректно
невозможно. Клиренс креатинина для CRUSADE берётся из уже рассчитанного
значения по Кокрофту-Голту (отдельно вводить его не нужно).

Поля «рост» в формулах не используется (ни в одной из четырёх шкал/формул
рост не участвует) — оставлено как общее клиническое поле пациента.

## Как открыть проект

**Вариант А (проще всего, минимальный риск конфликта версий Gradle):**
1. В Android Studio: File → New → New Project → **Empty Activity** (Compose), Kotlin,
   package name `com.cardioacs.app`, minSdk 31.
2. Замените сгенерированный `MainActivity.kt` файлом из этого проекта.
3. Скопируйте `Calculators.kt` и папку `ui/theme` в тот же пакет.
4. Добавьте в зависимости `app/build.gradle.kts` строку
   `implementation("androidx.compose.material:material-icons-core")`
   (используется иконка стрелки в выпадающем списке Killip).
5. Синхронизируйте проект (Sync Now) и запустите.

**Вариант Б (открыть проект как есть):**
1. Откройте папку `CardioACS` целиком через File → Open в Android Studio.
2. Если Android Studio сообщит об отсутствующем Gradle wrapper jar —
   согласитесь на его создание/загрузку (Studio делает это автоматически),
   либо выполните в терминале `gradle wrapper` при наличии локального Gradle.
3. Дождитесь Gradle Sync, запустите приложение на эмуляторе/устройстве
   с Android 12+.

Версии в проекте (при необходимости Android Studio предложит обновить —
это нормально): AGP 8.6.1, Kotlin 1.9.24, Gradle 8.9, Compose BOM 2024.09.00.

## Формулы и источники

- **СКФ (CKD-EPI 2021, без поправки на расу)** — Inker LA, et al.
  *N Engl J Med.* 2021;385:1737-1749.
- **Клиренс креатинина (Кокрофт-Голт)** — Cockcroft DW, Gault MH.
  *Nephron.* 1976;16(1):31-41. Используется фактическая масса тела.
- **Стадии ХБП** — по величине СКФ/клиренса, классификация KDIGO 2012
  (C1 ≥90, C2 60-89, C3a 45-59, C3b 30-44, C4 15-29, C5 <15).
- **Шкала GRACE** — классическая 8-факторная шкала внутригоспитальной
  летальности (Granger CB, et al. *Arch Intern Med.* 2003;163:2345-2353).
  Пороги тактики КАГ — ESC Guidelines for NSTE-ACS 2020 (>140 баллов —
  ранняя инвазивная стратегия <24 ч, 109–140 — <72 ч, <109 — селективно).
- **Шкала CRUSADE** — Subherwal S, et al. *Circulation.* 2009;119:1873-1882.

## Дисклеймер

Приложение — калькулятор для помощи в клинических расчётах, не заменяет
клиническое суждение врача. Формулы реализованы по опубликованным
первоисточникам и проверены юнит-тестами на контрольных примерах, но перед
использованием в клинической практике рекомендуется независимая верификация
результатов на нескольких известных случаях.
